Changes
-------
* Models converted to the Minecraft 26.3 format: NeoForge-only fields (render_type, loader) removed,
  "neoforge:separate_transforms" resolved into item model definitions with select on display_context,
  item overrides converted into range_dispatch definitions on custom_model_data.
* Item model definitions (assets/<namespace>/items/) added for all models.
* Skewer models: ingredient colours as tint indices, bite stages mapped to minecraft:use_duration; models that
  use textures from both the item and block atlas redirected to copies under textures/item/_block/.
* Atlas entries added for additional texture folders.
* German translations and additional texts for the server plugin added.
* The pepper tree (log, leaves, sapling) is replaced by an own pixel-art Sichuan pepper bush (6 growth stages)
  and seed item, using colours from the original pepper leaf and Sichuan pepper textures.
* Cookbook images of the items rendered from the models.
